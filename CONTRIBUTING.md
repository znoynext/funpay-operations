# Contributing

This repository is proprietary and is not open source. Do not submit secrets,
customer data, transaction data, databases, backups, logs, or local settings.

Changes must use a branch and pull request. Before committing, run the tests,
review the diff, and scan the changed files for credentials. Do not add
automation that controls a visible browser, mouse, or keyboard.

Do not implement real FunPay operations without explicit confirmation from the
repository owner for the concrete operation.
